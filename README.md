# robosys2025

ロボットシステム学の課題1のプログラムをまとめたリポジトリです。
標準入力を利用した簡単な計算プログラムや、文章の雰囲気を数値化するデモプログラムなどが含まれています。

### ● moodcalc  
文章中の単語をもとに、簡易的な「ポジティブ / ネガティブ」度を計算するデモプログラムです。  

---

## 使用例

```bash
echo "今日はとても楽しかった" | ./moodcalc
　　 入力文字数: 11
     肯定語 出現数: 1
     否定語 出現数: 0
     文長ボーナス: 0
     感嘆符ボーナス: 0
     強調語ボーナス: 1
     否定強化ペナルティ: 0

     生スコア: 2  (範囲 -10..+10)
     正規化スコア: 1  (範囲 -5..+5)
     傾向: 明るめ

     肯定語ヒット: 楽:1
```
